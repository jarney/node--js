# NodeJS

NodeJS is a graph oriented programming language front-end which
is an experimental approach to general-purpose programming
language design.  It is not a programming language by itself,
or rather, it can be used as a front-end to multiple
programming languages by replacing the traditional lex/parse
stage of a compiler front-end by directly representing
programs as graphs (Nodes and Edges) which represent the
flow of data in a computation.

This approach is not new and similar techniques have been used
for years in special-purpose systems like Blender, NodeRed,
Unity, and many others.  What this system provides is a general
framework which allows programs of this nature to be 1) General-purpose
rather than specific to an individual application or domain.
2) Portable and standard, providing a general framework
for defining and implementing special-purpose nodes. 3) Standardization
of format, providing a way to serialize, edit, and manage programs
in many contexts, not necessarily specific to one.

## Why?
This is a passion project.  It was bourne out of an admiration of
node-based programming used in various existing software projects
and a desire to bring this technique into more general
and widespread use.  It is a very natural way to represent
programs to humans.
